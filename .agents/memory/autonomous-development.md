---
name: Desarrollo autónomo
description: Preferencia del usuario para cómo avanzar con el desarrollo de esta aplicación.
---

Trabajar en el desarrollo de forma autónoma y seguir avanzando; detenerse solo si hace falta una interacción imprescindible del propietario.

**Why:** El usuario pidió explícitamente que el desarrollo continúe sin pausas innecesarias.

**How to apply:** Tomar decisiones razonables según los requisitos y el código existentes, completar y verificar unidades de trabajo coherentes. Preguntar solo cuando falte un dato o una decisión de negocio que no se pueda resolver con seguridad a partir del contexto disponible.
