---
name: Límites de compatibilidad con Versat
description: Criterio para no atribuir compatibilidad contable a un formato reconstruido a partir de un ejemplo.
---

Tratar la exportación `.Fac` como candidata de prueba hasta que el usuario confirme una importación en una copia de su Versat Sarasola. No anunciar compatibilidad certificada por tener catálogos o reproducir un ejemplo.

**Why:** El usuario proporcionó una muestra de una operación, no una especificación completa. No hay un Versat de escritorio accesible desde este entorno para comprobar campos, codificación, talones, duplicados o variantes de operación.

**How to apply:** Para ampliar a mercancías, impuestos, descuentos, otras monedas MC/OM o agrupadores desconocidos, pedir un ejemplo/reglas y validar antes. No inferir numeración ni autorización de firmas a partir de una factura histórica. Separar una firma/cuño escaneados de una firma digital verificable.
