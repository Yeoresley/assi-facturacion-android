name: Secuencia web y Android
description: Orden de desarrollo acordado para la aplicación de facturación ASSI.
---

Primero terminar y dejar estable la aplicación web; después comenzar el desarrollo de la aplicación APK para Android.

**Why:** el usuario definió explícitamente esta secuencia para el proyecto.

**How to apply:** no iniciar el trabajo de Android antes de que la versión web esté terminada y lista.
