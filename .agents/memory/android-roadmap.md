El propietario autorizó comenzar la aplicación Android ahora, en paralelo con el trabajo restante de la web. Iniciar Android no significa que la web esté lista para producción.

**Why:** el propietario cambió la prioridad y pidió empezar la APK antes de declarar terminada la web.

**How to apply:** avanzar con Android reutilizando la API y la identidad visual de ASSI, mientras continúa la estabilización web; conservar la limpieza de datos de prueba y las comprobaciones de producción como trabajo separado.
